## What it does

`main.py` writes a single funny one-line resignation letter to
`/output/entry.txt`. The letter comes from a wedding DJ, who has played
200 first dances and quits before the bouquet hits him: the job is
soundtracking other people's happiest nights, and the punchline treats
the bouquet like a hazard he has dodged 200 times and will not dodge
again.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

The entry is one line, 1-140 characters, plain UTF-8 text.
